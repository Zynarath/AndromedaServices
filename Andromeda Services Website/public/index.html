The control panel

Everything you'd SSH in for, in your browser.

The same panel we built to run our own group's servers. Nothing hidden behind support tickets.

Live console

Watch the server log as it happens and send commands, with history and one-tap quick commands.

One-click mods

CurseForge modpacks, ficsit.app for Satisfactory, uMod for Rust. Dependencies and versions sorted out for you.

Full file access

Edit configs in the browser, drag in whole folders, upload your old world, download anything as a zip.

Backups you can trust

One click or on a schedule, keep the newest few, restore in a minute. A backup is taken before every modpack update.

Schedules

Daily restarts with in-game warnings, interval backups, timed commands and automatic game updates.

Your group, your rules

An account for every friend with their own permissions: start/stop, console, files, mods, backups. Two-factor sign-in included.

Discord built in

A bot posts when servers go up, go down or update, with a channel per server and the address to join.

Private by default

Join passwords and whitelists out of the box, so only the people you invite can get in.

FAQ

Good questions.

Something else? Ask it in the waitlist form's note and we'll answer.

When does Andromeda open?

As soon as the server hardware is in place. Everyone on the waitlist hears about it first.

How much will it cost?

Plans and prices are announced at launch. The waitlist tells us which games and group sizes to plan for, so signing up helps shape them.

Can I bring my existing world or save?

Yes. Upload it through the file manager (whole folders and zips work) and the server picks it up.

Can my friends manage the server too?

Yes. Give each friend their own panel account and choose what they can do, from just starting the server to full file access.

Do mods and modpacks cost extra?

Mod support is part of the panel for every game that has it: CurseForge for Minecraft and ARK, ficsit.app for Satisfactory, uMod for Rust, and zip mods for 7 Days to Die.

What happens to my world when the server restarts or updates?

Servers save before they stop, every time. Modpack updates take a backup first, and you can roll back from the Backups tab.
